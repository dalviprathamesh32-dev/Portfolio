Threat Model & Honest Limitations

Protects against: a database or Redis leak (only ciphertext is stored) and messages lingering after they’re read.

Link possession: anyone with the full link, #key included, can read the message once.

You trust the served JavaScript: a compromised server or an XSS bug could steal the key. Strict CSP and zero third-party scripts reduce this, not remove it.

Metadata is visible: the server still sees IP address, message size and timing. It’s not anonymity.

Not forensic-grade deletion: Redis may persist to disk depending on config.

Public demo limits: per-IP rate limiting and a strict CSP are on, but there is no authentication, and anyone who learns only the message ID (not the key) could burn it.
